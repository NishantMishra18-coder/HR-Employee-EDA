# HR Employee Data Analysis (EDA)

## Project Overview

This project analyzes HR employee data using Python to understand workforce patterns, employee attrition, department distribution, age, and monthly income.

## Objectives

* Explore and summarize HR employee data.
* Identify trends and patterns.
* Analyze employee attrition.
* Create visualizations to present findings.
* Check missing values and duplicate records.

## Tools Used

* Python
* Pandas
* Matplotlib
* Google Colab

## Analysis Performed

1. Dataset overview and descriptive statistics.
2. Missing values and duplicate checks.
3. Department-wise employee distribution.
4. Employee attrition analysis.
5. Age distribution.
6. Monthly income distribution.
7. Overtime and attrition comparison.

## Key Findings

* Total employees analyzed: 500.
* Average employee age: 35.77 years.
* Average monthly income: 8,126.28 (dataset units).
* Employee attrition: 13.2%.
* Missing values: 0.
* Duplicate rows: 0.

## Conclusion

This project uses exploratory data analysis and charts to understand workforce characteristics and employee attrition patterns. The findings can help HR teams investigate workforce trends and support data-informed decisions.
